  • Blog link included — drives curiosity

❌ What Hurts

  • Irrelevant tags: #solana, #ruby, #turtle, #humor
  • Personal posts get lowest reach (145)
  • No feedback loop — CastPA doesn't learn

3. The Hashtag Problem

Every post currently ships with 80–100 hashtags. LinkedIn's algorithm treats this as spam and reduces distribution. This is the single biggest fixable issue in CastPA today.

Current behavior — 100 random hashtags

Tags like #raspberrypi, #solana, #blockchain, #wecoded, #turtle, #ruby, #rails are attached to every AI/ML and Flutter post. These are irrelevant and actively penalize reach.

What good tags look like (10 max)

Trending from dev.to (top 5 by RAG similarity to post):

#RAG #MachineLearning #LLMs #VectorDatabases #AI

Profile-based tags (top 5 by RAG similarity to your content history):

#NLP #embeddings #DataScience #Python #DeepLearning

Removed junk (current behavior):

#raspberrypi #solana #turtle #ruby #wecoded #blockchain #humor #weeklyretro

LinkedIn API limitation to know

LinkedIn does not allow fetching impressions/interactions programmatically for personal profiles (only company pages via Marketing API). This means the analytics layer will require the user to manually enter performance data — or you track only what CastPA itself posts via the Share API response metadata.

6. Implementation Roadmap

Phase 1
Fix Now

Hashtag Overhaul

  • Remove the 80-100 random tag dump completely
  • Integrate dev.to API for weekly trending tag fetch
  • Build Gemini prompt to extract profile-based tags from LinkedIn post history
  • Implement RAG similarity scoring (5 trending + 5 profile = 10 tags max)
  • Store tag sets with embeddings in local DB / Firestore
Phase 2
Analytics

Performance Tracking & Recommendations

  • Build manual input UI for logging impressions/interactions per post
  • Weekly analytics summary: top posts, top categories, top tags
  • Feed top-performing tags back into RAG boost scores
  • Recommend content type and topic based on previous week's data
  • Post timing recommendation based on historical performance pattern
Phase 3
Smart Layer

Feedback Loop + Intelligence

  • Auto-detect missing call-to-action in generated posts
  • Tag performance memory — system learns which tags = high impressions for this user
  • Hook strength scorer — rate the opening line of each post
  • Post structure analyzer — identify if bullet format, length, tone matches top posts
  • Weekly digest: "Here's what worked last week and what to post this week"

7. Is CastPA Delivering Real Value?

Current state: Mostly just another tool

Impressions of 145–468 across 8 posts is baseline LinkedIn activity — not proof the app is adding value. The hashtag spam is making things worse, not better. Without a before/after baseline, there is no clear evidence of improvement yet.

After Phase 1 + 2: Real product territory

Fixing hashtags alone will likely improve impressions by 20–40%. Adding the analytics feedback loop — where CastPA tells you what to post, when, and why based on YOUR data — is what makes it a product people would pay for, not just a Claude wrapper.
